# Events v2 — AV console adapter

The shipped access client admits exact bounded AV payloads. av-console.js projects allowlisted data bound to the current event, Live and grant asset path; stale revisions, playback IDs, access generations and late acknowledgments cannot retarget controls. Lost acknowledgments recover through a fresh authorized read without replaying the mutation. The existing EventAVRuntime, audiovisual-state and ReactionRuntime remain authoritative.

Stage/Speaker select prepared audio/video/resources/playlists, pause/resume/stop/fade audio, seek, loop, set shared volume, edit literal text, clear overlays, draw transient slide-bound strokes and select the twelve existing Audio React modes. Player uses the same single-line emergency menu and current-playback ended feedback. Destructive/replacement confirmations bind to the observed revision. Drawing sends only bounded normalized points after pointer release, cancels on slide/focus/access loss and never transmits local clocks or identity. Público sends only allowed emojis and sees its own socket echo; no catalog, playback, asset paths, counts or other people's reactions. Player renders at most fifty authorized transient reactions; Stage/Speaker see aggregates.

Only Player opens credentialed same-origin media elements. An explicit activation button handles browser autoplay rejection. Authoritative positions and independent channel states synchronize playback; obsolete ended callbacks cannot advance replacements. A local fade adjusts volume but only the server commits replacement/stop. Already playing media is retained during transient connection recovery; new operations and callbacks require current access. Denial, finish, pagehide and changed bindings stop/retire media. No promise of durable offline provisioning, precise cross-device decode timing, instant buffered-byte revocation, browser/OS codec support or production-reader availability follows from Node DOM/SQL fixtures.

Audio React reuses the existing renderer. Its init accepts an optional logoUrl without changing the legacy default; Events supplies the existing same-origin icon. Its two 3D modes retain the existing pinned Three/GSAP dependency URLs. Console CSP allows only those two exact script URLs plus self, same-origin media/images and existing self connections; it adds no inline/eval permission. Availability without those already cached dependencies is not certified. Physical audio/decode/analyser and operator acceptance remain pending. The prepared public QR identity is validated but no QR destination is invented: generation/rendering waits for the portal/access URL contract. Private preparation/storage readers and prevalidated local slides/media remain Phase 2; durable multiinstance execution remains Phase 3. Events remains off and no show.immersalive.com DNS is needed.
