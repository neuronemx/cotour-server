# Eventos v2 Phase1C — private slides and prepared languages

This increment stacks on the AV console increment. It adds a private image delivery adapter and renders the canonical transmitted slide beneath audiovisual layers. Stage/Speaker receive separate current-control and next thumbnails; advancing a paused preview does not change the transmitted image. Previously loaded images/video remain visible during transient access recovery; confirmed denial, scope changes and finalization retire images and stale callbacks.

`EventSlidesRuntime` accepts only event/live/deck/version-owned, immutable preparations. The parent preparation pins `slideDigest`, the SHA-256 of normalized image descriptors and language configuration. Parent Live reads and navigation reject changed/removed digests once an execution is initialized. Each slide requires Spanish, with optional English. Prepared `presenterLanguage` controls Stage/Speaker/Player; only Público can choose personal ES/EN. Missing English images or text fall back to Spanish. Personal preference is memory-only, retained for same-Live reauthorization and cleared on denial or a different Live.

Images use `/api/events-v2/live/:eventId/:liveId/:grantId/slides/:digest/:language/:index/:variant`. Every GET/HEAD/conditional/range request authorizes the current HttpOnly browser grant and resource scope. Público/Player can fetch only the transmitted full image; trusted Stage/Speaker can fetch prepared full images and thumbnails. Player cannot override the operational language. The adapter accepts JPEG/PNG/WebP descriptors only, verifies opener metadata and opens streams outside the SQL authorization transaction. Responses are no-store, same-origin, no-referrer and nosniff; external/public URLs, query paths and cross-site requests are rejected.

`events:slides:snapshot` is a personal read with the exact payload `{language:'es'|'en'}`. It never changes global language or navigation. The shipped client normalizes canonical same-origin URLs, fences access generations, Live identities, revisions, content versions and superseded requests. The page installs the successfully preloaded image element directly, avoiding a second no-store request. Async image callbacks cannot restore revoked or superseded content.

Poll and Knowledge pages use already-bounded, server-prepared English titles/questions/options/reveals where available. Language renders preserve selected answer IDs and canonical receipts. Static operational labels, unprepared raffle translations, personal-result labels, user-generated messages/questions and participant names keep their original text; this increment does not promise complete interface localization or generate translations.

Production readers remain deny-by-default. Phase2 must implement private preparation, verified immutable image openers, deck conversion/storage and portal publication. The SQL/Socket.IO tests use controlled private image preparations and disposable schemas; they are not operator acceptance of real decks or a physical-browser rendering certificate. Phase3 retains ownership of durable/multiinstance state and global idempotence.

Main, public feature flag, Beta/Production and DNS are outside this increment. No `show.immersalive.com` DNS is required yet. Phase1C and Phase1 remain open.
